    Wi-Fi · redes salvas
    
      
    O aparelho conecta na rede salva com o sinal mais forte. Deixe a senha em branco para manter a atual. Redes ocultas: deixe-as no topo da lista.
    
      
    
      
    
      
    
      
    Toque numa rede encontrada para adicioná-la. Mudanças no Wi-Fi reiniciam o aparelho.
    
    
    

    
    
      
    Hora
    
      
    
        
        
        
        
        
        
        
        
        
        
    Ao ligar e salvar, o aparelho mostra uma tela de teste por 20 s. Se a imagem estiver perfeita, aperte o botão do aparelho para manter. Sem o botão, volta sozinho para 40 MHz.

    Versão instalada
    
      
    
    
    
    
    
      
    Atualizar pelo navegador
    
      
    Escolha o arquivo .bin de atualização do Radar360. Mantenha o aparelho ligado; ele reinicia sozinho no fim.
    
      
    
      
      
    
    
    
    
    
      
    Pacote visual
    
      
    Fontes, fundos, silhuetas, bandeiras e lua dos temas ficam numa parte separada da memória. Só precisa enviar quando uma versão nova pedir (arquivo radar360-pack).
    
      
    
      
    
      
      
    
    
    
    
    
      
    Cópia das configurações
    
      
    Salva num arquivo as redes Wi-Fi, senha do painel, chave da CARTO, hora, brilho, telas, temas e ordem. As fotos não entram. O arquivo tem senhas: guarde em lugar seguro.
    
      
    
    
    
    
    
      
    Aparelho
    
      
    O padrão de fábrica apaga redes Wi-Fi, senha e preferências. O aparelho volta no modo configuração (rede Radar360-XXXX).
    
      
    
      
    Modo recuperação: um sistema mínimo, separado, só para enviar firmware e pacote pelo navegador. Também abre segurando o botão do aparelho por ~5 s ao ligar.
    
    
    
  
    
  
    
    
    
      
    Aparência do painel
    
      
    Vale só para este navegador (celular e PC podem ficar diferentes). Não muda nada no aparelho.
    
      
      
    
      
      
    
      
      
    
      
      
    
      
    
    
  
    

    



    
  
    
    
    
    
    
    
    
    
    
    
  
    

  
    
    
    
      
    Relógio
    
      
      
    No realista há sol, nuvens, chuva caindo, raios, neblina, noite com lua na fase certa, amanhecer e pôr do sol.

    Mapas
    
      
      
      
    A CARTO passou a exigir uma chave, que é grátis: peça em carto.com/basemaps/apikey e marque uso pessoal (não comercial). Sem chave, o aparelho usa o OpenStreetMap. No estilo escuro com OpenStreetMap o mapa é escurecido.

    Horóscopo
    
      
    Signos para exibir (com mais de um, eles se alternam; toque longo passa para o próximo):
    
      
    
      
    
        
        
        
      
    
      
    A previsão é montada no próprio aparelho, em português, e muda todo dia para cada signo (é para diversão). A “Lua em …” é calculada de verdade.
    
    
    
    
    
  
    

  
    
    
    
      
    ID DMR (hotspot)
    
      
    
        
        
        
        
      
    
      
    Lê a tabela "Last Heard" do dashboard do Pi-Star ou WPSD pela rede local. Toque longo alterna entre destaque e lista.
    
    
    
    
    
  
    

  
    
    
    
      
    PC (Windows)
    
      
    
        
        
        
      
    
      
    
      
    Pelo nome funciona quando a rede do Windows está como Privada (Configurações → Rede → Propriedades). Se não achar, use o IP; para o IP não mudar, reserve-o no roteador.
    
      
    No PC, abra o LibreHardwareMonitor (grátis) e ligue Options → Remote Web Server → Run (porta 8085, sem senha). Na primeira vez, o Windows pergunta se libera a rede: aceite. Para não esquecer, marque também Start Minimized e Run On Windows Startup. Depois ligue a tela "PC" em Telas.
